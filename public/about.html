About This Project

A web-based Intrusion Detection and Prevention System (IDS/IPS) developed as an academic project for the Information Security course.

Project Overview

This project demonstrates how web applications can detect and prevent common attacks such as SQL Injection and Cross-Site Scripting (XSS). The system uses a signature-based IDS to analyze user input and an IPS to automatically block repeated attackers.

The system features a comprehensive 3-factor authentication mechanism that includes email/password verification, OTP-based authentication, and security question validation to ensure maximum security.
